# 🎲 3D Dice Game

A simple and interactive 3D Dice Game built with HTML, CSS, and JavaScript.

## ✨ Features

* 3D animated dice rotation
* Two-player gameplay
* Automatic score calculation
* Winner announcement after 3 rounds
* Reset game functionality
* Custom UI with background image and player section
* LinkedIn profile integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🎮 How to Play

1. Player 1 rolls the dice.
2. Player 2 rolls the dice.
3. The higher number wins the round.
4. After 3 rounds, the final winner is displayed.
5. Press the reset button to start a new game.
